summary: Learning Python from scratch by building a simple money management system in the terminal.
about:
  - PyMoney is a personal expense and income tracker that runs entirely in the terminal. You tell it how much money you have, add records such as "breakfast -50", view them and delete them, and it remembers everything the next time you open it.
  - It is a project-based learning exercise I did to learn the basics of Python.
play:
  - Tell it how much money you have.
  - Add records such as "breakfast -50".
  - View your records, or delete one.
  - Use find to total everything under a category.
playHeading: How to use
built:
  - I wrote it in Python, in three versions.
  - "PyMoney01.py: three lines that read a starting balance and one record, add them and print the result."
  - "PyMoney02.py: the procedural version, four small projects stacked in one file."
  - "PyMoney03.py: the current version, rebuilt around objects, with categories, a category-aware add and a find command."
  - "Topics it covers: input and output, data types and strings, sequences, sets and dicts, conditionals and loops, functions, file handling and exceptions, recursion, OOP, generators and the standard library."
